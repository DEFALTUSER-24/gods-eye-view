# Salud pública — CABA + Provincia de Buenos Aires

3139 points: CABA hospitals (general, especializados, de niños) and CeSAC from epok.buenosaires.gob.ar
(Mapa Interactivo BA, CC-BY GCBA) plus 3052 public health establishments of Provincia de Buenos Aires
(catalogo.datos.gba.gob.ar "Establecimientos de salud públicos 2025", CC-BY 4.0). Snapshot 2026-09-10.
Rebuild: `node scripts/build-caba-static-layers.mjs salud`.
