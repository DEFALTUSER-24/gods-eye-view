# RENABAP 2020 — barrios populares del AMBA

1200 polygons (bbox -59.0,-35.1,-58.2,-34.3) from the Ministerio de Obras Públicas GeoNode
(`geonode:renabap2020_smz`, https://geoportal.obraspublicas.gob.ar/geoserver). Public national registry.
Rings simplified 0.00015° (17839 → 10889 vertices). Fields: barrio, partido, localidad, year, families,
electricity/water/sewage access. Snapshot 2026-09-10. Rebuild: `node scripts/build-caba-static-layers.mjs renabap`.
